## 行为

- 保留报名提交前的二次确认和在途提交锁。请求结束后使用独立结果弹窗，展示成功、跳过、失败和待确认数量，以及每个请求组合的账号、赛事与结果；失败保留可读原因并转义显示。
- 提交前冻结账号标签（含完整 UID）和赛事名称。返回结果按账号 ID 与赛事 ID 匹配；改名、切换账号和页签、周期刷新不会重写本次结果。迟到结果不会修改新账号页面的勾选状态。
- 移除列表中的旧长结果区。弹窗标题、关闭按钮和汇总固定，逐项列表内部滚动。关闭时恢复页面滚动和可用焦点；原触发控件不可用时聚焦应用标题。关闭后轮询不会重新弹出。
- 弹窗期间隐藏两个悬浮按钮，禁止下拉刷新手势；支持关闭按钮和 Escape/原生 dialog cancel。原生 modal dialog 隔离背景；不支持 showModal 的环境使用遮罩、背景 inert 和焦点循环兼容路径。
- 网络异常、120 秒超时、响应缺项、重复项或未知结果均保守标记为待确认，不计为成功。明确提示先查询官方报名状态，勿直接重复提交；没有自动重试。超时中止浏览器等待不能证明服务器操作已取消，仍需核对官方状态。
- 成功项取消勾选、其他项保留的原规则继续有效；切换账号后不修改新页面的选择。Service Worker 更新为 `sve-v17-batch-result-dialog`，沿用 API 不缓存策略。

## 私密审查后续修复

在 `4c9e5e4` 后修正错误分类和历史恢复两个问题；本节描述最终行为，取代上一轮对所有 `ok:false/error` 的统一失败分类：
