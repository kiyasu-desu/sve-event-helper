## 回退与停止条件

- 清单漂移、未知写入者、新订阅、数据/配置不一致、权限失败或关键健康失败时，不继续激活。
- 切换开始后失败：先停 agent 和看护，使用**本候选包外保留的 release.py** 执行 rollback/recover，校验原清单/字节；不恢复旧业务数据覆盖最新数据。
- 按受保护备份恢复 watchdog 原 unit/drop-in，daemon-reload 后恢复原 agent 与 timer 状态；旧 poller 保持停止和禁用。撤销屏蔽只恢复原 unit 配置，不能启动旧执行器。
- 恢复后确认原生产完整 SHA、原 HTTPS/认证入口、数据成员和记录、服务身份权限以及手机状态。备份和发布目录保留供追溯，不删除私人数据或历史。
- 若新版服务故障，优先恢复服务再继续界面验收；不在半切换状态下反复操作手机。

本次实际未执行生产 apply、rollback、服务启停、unit 改写或屏蔽。完整入口、设备标识、账号身份、原始日志、配置和临时哈希记录仅在受保护或忽略位置保存，不提交仓库。
