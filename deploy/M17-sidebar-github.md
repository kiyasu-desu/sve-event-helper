# M17 侧栏左下角 GitHub 入口

日期：2026-11-07。分支：`codex/m17-sidebar-github`。基于已合并 M16 的 `origin/main`：`50566f8`，没有未合并代码依赖。

## 实现

- 在侧栏底部区域左侧加入 GitHub 图标，右侧保留设置。图标触控范围 48 × 48 CSS px，使用随主页提供的内嵌 SVG，具有独立无障碍名称，不请求外部图片或图标服务。
- 菜单链接在独立区域滚动，底部入口不随长菜单滚走；保留原无 modal dialog 的兼容导航。GitHub 和设置保持独立的点击区域与间距。
- 项目链接集中配置在主页 `sve-repository` meta 中，已核对与当前 origin 去除 `.git` 后一致。仅接受普通 GitHub HTTPS 仓库路径，缺失或不符合格式时隐藏入口，不接受查询参数、片段或内嵌认证信息。
- 使用普通同窗口链接及 `noreferrer`。现有 Android 源码对非原生登录 scheme 返回普通 WebView 导航，因此无需依赖新窗口能力、修改原生代码或重装 APK。侧栏提供「私有仓库需 GitHub 登录及访问权限」提示，权限由 GitHub 处理。
- Service Worker 更新为 `sve-v22-sidebar-github`。图标和元数据均在已有发布清单的主页中，没有新静态文件或后端接口。

- 真实 Chrome 使用合成 API 与 GitHub 200/404 页面替身，在 320 × 568、360 × 640、640 × 320 触屏视口验证；向菜单加入 40 项并放大菜单字号，滚动到菜单末尾后底部入口位置不变。GitHub 点击范围保持 48 px，与设置实际间距 155 px，两者均可点击。
- 模拟可访问/无权限页面均以同窗口普通链接进入，浏览器返回可回到原设置页，没有额外窗口、脚本异常或业务 POST。截图已目视核对，图标可辨认。
