# M18 当前账号两行展示

日期：2026-11-08。分支：`codex/m18-account-header`。基于已合并 M17 的 `origin/main`：`c2e41e1`，没有未合并代码依赖。

## 展示行为

- 共用顶栏的账号块固定为两行：第一行「当前账号:」，第二行为昵称及括号包围的完整数字 ID，去掉该处原有的 `UID` 字样。
- 昵称与 ID 分为独立元素，昵称可省略并通过完整文本及 title 获取原值，ID 不参与收缩或省略。使用现有规范化 `account_id` 字符串，避免长 UID 经 JavaScript Number 转换丢失精度。异常超长 ID 超出账号行时可在该行横向滚动，不扩展页面宽度。
- 大屏分配标题、账号块、时钟与 44 px 菜单按钮四列；560 px 及以下将标题和时钟放在上排，账号两行放在下排，菜单跨排固定在右侧。默认窄屏顶栏约 79 px，宽屏约 57 px；账号改名、切换或未登录时布局高度保持稳定。
- 成功状态刷新、选择账号和身份视图清理时更新账号块。未登录或身份失效时显示「未登录」，清除括号与旧 ID。只使用文本节点填充昵称，特殊字符不会成为 HTML。
- 其他账号卡片、操作请求、确认框和批量结果继续沿用原稳定身份及展示约定。Service Worker 更新为 `sve-v23-account-header`，不增加静态文件、后端接口或数据迁移。

## 验证

`node --test tests/test_identity_ui.js`：87 项全部通过。覆盖 6、10、20 位合成 ID、特殊字符、同名不同 ID、切换时即时显示、身份失效清除，以及已有的改名、迟到响应、登录、导航、设置、批量报名和 PWA 回归。测试另确认其他 `accountLabel` 调用仍显示原有完整 UID 标签。

真实 Chrome 加载实际主页，网络由合成 API 替身接管：

- 320 × 568、360 × 640、640 × 320 横屏及 1280 × 800 视口，分别在赛事、订阅和设置页检查 6/10/20 位 ID 及未登录状态，共 48 组。昵称使用很长的特殊字符文本，均按文本显示并省略，20 位 UID 在可用区域内完整显示，无横向页面溢出。
- 第一行标签和第二行账号信息分开，标题、时钟及菜单不重叠；菜单点击区域保持 44 × 44 px，可以打开和关闭。每个视口的登录/改名/ID 变化及未登录状态下顶栏高度一致，无脚本异常或业务 POST。
- 实测同名账号不同 ID 的后台切换及昵称刷新。320 px 设置页截图已目视核对。
- 回环静态合成服务实测 v22 → v23 SW 更新，等待新控制器接管后旧缓存移除，API 未缓存；设置页离线刷新和联网恢复、420 px 滚动及有效选择恢复通过。该服务没有启动业务应用，也没有访问官方报名或通知接口。
