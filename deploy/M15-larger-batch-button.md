# M15 增大一键报名悬浮按钮

日期：2026-11-07。分支：`codex/m15-larger-batch-button`。起始提交：`d0a1c2d2f5f40e304b77a8fc82c1a697320e6370`，为已合并 M14 及其审查修订的 `origin/main`，没有未合并代码依赖。

## 变更

- 一键报名按钮使用独立的 `--batch-size: 64px`，保持圆形和两行「一键」「报名」，字号为 `1rem`。返回顶部和下拉刷新指示器继续使用原有 48 CSS px。
- 赛事页底部预留空间随 64 px 按钮增加 16 px，继续叠加安全区及统一边距；订阅页仍沿用原有留白。
- 保留现有选择有效性、页签和遮罩显隐、提交中禁用、二次确认及结果弹窗逻辑。Service Worker 更新为 `sve-v20-larger-batch-button`。

## 验证

`node --test tests/test_identity_ui.js`：77 项全部通过，包括 M14 审查后的拒绝分类、历史返回、提交去重、轮询、选择和缓存策略。此次为局部样式调整，没有新增复述样式值的单元测试。

真实 Chrome 无头模式加载修改前和修改后的完整 HTML，所有请求由合成接口替身接管，未启动业务服务或访问官方接口。比较结果：

| 场景 | 一键报名（修改前 → 后） | 返回顶部 / 刷新球 | 赛事页底部留白（修改前 → 后） |
|---|---|---|---|
| 320 × 568，根字号 16 px | 48 → 64 px | 48 / 48 px | 80 → 96 px |
| 360 × 640，根字号 24 px，模拟底部安全区 34 px | 48 → 64 px | 48 / 48 px | 114 → 130 px |
| 640 × 320 横屏，根字号 24 px，模拟底部安全区 34 px | 48 → 64 px | 48 / 48 px | 114 → 130 px |

上述场景按钮均保持圆形，文案在按钮内完整容纳，无横向溢出。滚到页面底部时，最后一个内容区与大按钮顶部至少相隔约 16 px。截图已目视复核。桌面 Chrome 没有物理刘海；安全区测试通过替换底部偏移变量模拟，放大根字号也不能替代手机系统字体设置验收。

浏览器交互验证通过：空选/只选账号隐藏，双侧选择显示；侧栏及结果弹窗打开时隐藏；切换订阅页隐藏，返回后恢复有效选择；提交中禁用，轮询后仍禁用，重复调用仅产生一次模拟提交；取消最后一个赛事勾选隐藏。点击返回顶部能回到 0 并隐藏按钮。没有页面脚本异常。
