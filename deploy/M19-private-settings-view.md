# M19 空白设置表单与隐私展示

日期：2026-11-08。分支：`codex/m19-private-settings-view`。基于已合并 M18 的 `origin/main`：`3e22170b6988b678eecec113c1b89edde9b5362b`，没有未合并代码依赖。

## 页面与保存规则

- 设置页文本、密码和数字输入在首次打开、重新进入及成功保存后为空，使用通用提示。离开设置页清除输入；浏览器恢复缓存页面时也清除，普通前后台恢复、轮询及重连保留正在编辑的输入。慢保存返回后不会清除请求发出之后的新输入。
- 展示「已配置/未配置」、来源和可编辑状态。启用及 SSL 开关反映真实状态；环境变量管理的字段保持空白并只读。通知密钥和邮件授权码使用密码控件；页面不把输入写入 localStorage、IndexedDB 或业务缓存。
- 移除配置摘要、路径、地址、邮箱、收件人、密钥头尾、原始连接错误及通知发送诊断的回显。设置反馈使用固定类别及字段名称，不显示服务端异常原文。普通业务账号昵称与 UID 展示不属于本次配置隐私隐藏范围。
- 连接保存先从完整旧配置合并非空更新，再校验主机、用户和端口。留空保留原私钥选择及各端口；首次默认 SSH 22、转发及代理 8901。校验失败不启动隧道、不修改配置。停用保留连接参数，以便再次启用时空白保存仍能使用原配置。
- 保留本机调度器和远端执行权保护。新隧道启动后才提交配置；启动或保存失败时保留旧配置并清理替代连接、尝试恢复旧隧道。若原连接恢复失败，保留原远端模式，不隐式交给本机执行。启动成功不等于实际 SSH/代理连接已验证，页面仍以状态读取结果为准。
- 通知保存合并 settings、界面文件及环境变量后的有效配置再校验，只更新实际填写的字段和主动提交的开关。环境变量字段不写入影子值。SMTP 首次默认端口 465，未配置发件人时沿用邮件账号。显式 `clear_secrets` 保留原有移除界面密钥覆盖值的语义；普通空白不清除。无效字段或损坏的配置文件不被空配置覆盖。

## 接口与兼容

`/api/notify/config` 的读写响应只返回 `channels` 中的开关与 `字段__set`、`字段__source`、`字段__editable`，不返回文本、数字配置值、密钥掩码、配置路径或环境变量内容。通知测试仍调用原完整配置，响应只给通道、成功标记和通用结果。

`/api/remote/status` 只返回连接配置状态、隧道运行标记及代理可达标记；`/api/remote/config` 不回传原配置。`/api/state.remote` 也只提供状态，代理转发旧服务端响应时同样处理。未被当前网页使用的全局 `log` 兼容字段返回空列表，避免历史连接诊断进入浏览器；订阅自身的业务日志继续保留，详细运维诊断保留在执行端原受保护日志渠道。

已检查仓库内调用方，没有发现依赖读取这些配置原值的原生客户端或内部执行器。请求字段、`ok`、开关及已有身份协议保留；配置状态读取响应有意改为最小视图。旧壳读取新接口时不会收到个人配置，但完整状态显示应随本次页面/SW 一起更新。内部 `STATE`、连接对象、通知解析与发送仍取得原完整值；没有数据 schema 迁移。
