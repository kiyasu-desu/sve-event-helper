# M16 独立设置页与侧栏入口

日期：2026-11-07。分支：`codex/m16-settings-page`。基于已合并 M15 的 `origin/main`：`011bb77`，包含 M14 的审查修订，没有未合并代码依赖。

## 页面与交互

- 新增可直接访问、刷新的 `/settings` 服务端路由，与赛事页和订阅页共用主页外壳、固定顶栏及当前账号。自动报名执行位置、服务器连接和通知设置整体迁入设置内容区，赛事页保留账号与赛事业务区。
- 抽屉底部右侧提供「设置」入口，并标记当前页；底部容器为后续 M17 的 GitHub 入口预留布局。设置内容、抽屉在小屏和横屏下可滚动。无原生 dialog 的兼容导航同样提供设置链接。
- 三个页面沿用同一套 history 导航、各自滚动位置和状态。设置页直接打开支持部署前缀，例如 `/test-mount/settings`。返回赛事页时恢复地区、有效勾选及滚动位置，并重新核验赛事有效性。
- 设置进入、下拉刷新、前后台恢复和网络重连读取状态与通知配置。保存通知、测试通知、比较两端账号及启停执行位置仍由用户主动操作，沿用原有接口。操作结果在设置页专用状态区展示，网络失败时解除保存/比较按钮的忙碌状态并保留输入。
- 状态或通知读取失败时分别显示无法确认最新状态的提示；不会将离线缓存中的配置当成实时状态。通知输入有未保存编辑时，状态读取不重建表单，迟到读取不能覆盖较新的配置。成功保存更新通知摘要与表单。
- 此项完成页面迁移；设置字段的默认内容、隐私响应及空白更新协议由后续 M19 统一处理。
